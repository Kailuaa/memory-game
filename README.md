Memory Game — браузерная игра на запоминание пар карточек.

Описание

В игре 16 карточек — 8 пар одинаковых изображений.

Цель игры — найти все пары за минимальное количество ходов.

Возможности

* 16 карточек (8 пар);
* случайное перемешивание карточек;
* анимация переворота;
* подсчёт ходов и найденных пар;
* автоматическая проверка совпадений;
* блокировка кликов во время проверки несовпавших карточек;
* окно победы после нахождения всех пар;
* кнопка New Game;
* Leaderboard с 10 лучшими результатами;
* сохранение результатов в localStorage;
* закрытие модальных окон через Close, Escape и клик по фону.

Технологии

* HTML5
* SCSS
* JavaScript (ES Modules)
* DOM API
* localStorage

Сторонние UI и игровые библиотеки не используются.

Запуск

Проект использует JavaScript-модули, поэтому его рекомендуется запускать через локальный сервер.

Live Server

1. Откройте проект в Visual Studio Code.
2. Установите расширение Live Server.
3. Откройте index.html.
4. Нажмите Open with Live Server.
5. Игра откроется в браузере.

Также проект можно запустить с помощью любого другого локального HTTP-сервера.
